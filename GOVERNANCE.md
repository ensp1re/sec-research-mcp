# Governance

Roles from the product plan, not named people:

- Product/technical lead: scope, release acceptance, user testing
- Data engineer and financial-data reviewer: source adapters, normalization, methodology
- Application engineer: contracts, MCP/HTTP adapters, local packaging, charts
- Platform engineer: jobs, storage, security boundaries, deployment, recovery
- Independent reviewer for security and high-impact changes, not the sole change author

Apache-2.0 for the portable core. Optional managed hosting may later charge for compute, storage, indexing, and support. Pricing is not decided here.

At least two release-capable maintainers are required before promising long-term managed support.
